# VenusDrive component imagery

Generated with the built-in OpenAI `image_gen` tool on 2026-10-27 specifically for this project. These are representative educational illustrations, not photographs or verified diagrams of any saved vehicle. No third-party stock model, make/model identity, compatibility data or paid asset was introduced.

There are 28 separate main WebP images for 27 component entries: Differential and transfer case has two separately labeled assemblies. There are 27 thumbnail derivatives. Main images are 1024 × 1024; thumbnails are 192 × 192. All images use a white studio background, soft lighting, realistic materials and useful viewing angles. The cutaway car is a separate 1536 × 1024 asset at `../studio/silver-sedan-cutaway.webp`.

Canonical stable-ID mappings, category, alt text, applicability and explanatory sections live in `../../component-data.js` and `../../content.js`. Every main image carries the UI caption: “Example component. Appearance and location vary by vehicle.” This art cannot establish exact internal geometry, location, equipment, service requirements or fitment.

Each distinct component was generated separately, including the systems shown as coherent static assemblies. No interface screenshot, shared engine stand-in or cropped collage is used as a component image. The oil-filter image shows a spin-on example; the text explains cartridge designs. Low-voltage and high-voltage batteries are distinct assets. Differential and transfer case have independent images and real HTML labels.

The prompt and source-output manifest for every generated asset is in [`design-review/static-explorer/image-generation/`](../../../design-review/static-explorer/image-generation/). The [`image audit`](../../../design-review/static-explorer/image-audit.json) records decoded dimensions and optimized file sizes. `scripts/prepare-component-image.py` performs only format conversion and resizing; it does not modify depicted parts. Original generation outputs remain in their original generated-images location, and all project-consumed exports are saved here.
