# Website stage delivery

The source is in `web/public/`. Start it with `python3 server.py` from `web/`, then open `http://localhost:4173`. It is not published.

Implemented: responsive bright studio landing page and light-themed workspace, multiple vehicles and manual/catalog entry, mileage logs and explicit corrections, maintenance intervals and explanations, service visits with multiple tasks and attachments, history editing/deletion, actual expenses with separate currencies, in-app reminder settings/snoozing, data/CSV export, separate demo, educational parts/guides and a lazy-loaded multi-angle car explorer. The landing experience includes an interactive **three-angle image tour** with approximate visible-region markers; it is not real-time 3D and does not expose internal part geometry. The application explorer remains its separate, generic educational WebGL scene with 16 approximate component groups. Prepared Supabase auth, private-data adapter, ownership policies, version checks, private attachment policies and account-deletion function.
